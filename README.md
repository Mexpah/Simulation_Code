

### راهنمای استفاده از ابزار تحلیل نوسانگر (Balloon Oscillation Analyzer)

این پروژه شامل یک سیستم جامع برای پردازش داده‌های تجربی نوسان بادکنک هلیومی است. این ابزار به جای حل تحلیلی، از روش‌های عددی برای برازش (Fit) مدل‌های غیرخطی استفاده می‌کند.

#### ویژگی‌های کلیدی (Key Features):

* **فیلترینگ هوشمند:** شناسایی و حذف خودکار داده‌های ناقص یا پرش‌های نرم‌افزاری (Tracker Data) جهت جلوگیری از توقف محاسبات.
* **شبیه‌سازی دینامیک جرم-متغیر:** حل عددی معادلات دیفرانسیل حاکم بر سیستم با در نظر گرفتن متغیر بودن جرم طناب و درگ مرتبه دوم.
* **بهینه‌سازی دو مرحله‌ای:** استفاده از الگوریتم تکاملی (Differential Evolution) برای یافتن محدوده بهینه و روش (L-BFGS-B) برای همگرایی دقیق پارامترهای فیزیکی.
* **داشبورد تحلیلی:** امکان استخراج مستقیم جرم بادکنک و زمان‌های نیم‌تناوب برای گزارش کار علمی.

#### نحوه اجرا:

1. ابتدا کتابخانه‌های مورد نیاز را نصب کنید: `pip install numpy scipy matplotlib`
2. فایل‌های داده خروجی نرم‌افزار Tracker را با فرمت `tracker_data_N.txt` در پوشه برنامه قرار دهید.
3. کد `main.py` را اجرا کنید.
4. از طریق رابط گرافیکی (GUI)، ویدیو را انتخاب و با دکمه **Fast Fit** اولیه و **High-Precision** برای نهایی‌سازی، مدل را بر داده‌ها منطبق کنید.
5. در نهایت با دکمه **Global Analysis**، نتایج نهایی را در قالب یک گزارش جدول‌بندی شده استخراج کنید.
